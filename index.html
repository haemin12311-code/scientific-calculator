계산 기록

계산한 수식이 여기에 쌓여요.

    기록을 누르면 결과값이 현재 수식에 입력돼요.

    함수와 입력 안내
    • DEG는 도, RAD는 라디안입니다. 역사인·역코사인·역탄젠트의 결과에도 적용됩니다.
    • ln(x)는 자연로그, log(x)는 상용로그입니다.
    • ^는 거듭제곱입니다. 2^3^2 = 512, -2^2 = -4입니다.
    • %는 앞의 값을 100으로 나눕니다. 200×10% = 20.
    • n!은 0~170의 정수에만 적용됩니다.
    • Ans는 직전 계산 결과입니다.
    • x² · 1/x · ±는 선택한 부분, 선택이 없으면 수식 전체에 적용됩니다.
    • M+ / M−는 현재 수식 값을 메모리에 더하거나 뺍니다. MR은 불러오기, MC는 초기화입니다.
    • 실수 범위에서 계산하며 일반적인 부동소수점 오차가 있을 수 있습니다.
